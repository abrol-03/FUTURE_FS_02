# CRM Lead Management System

A full-stack CRM (Customer Relationship Management) application built using React, Node.js, Express.js, and MongoDB Atlas.

## Features

- Add new leads
- View all leads
- Update lead status
- Delete leads
- Store lead information in MongoDB Atlas
- REST API integration
- Responsive dashboard UI

## Tech Stack

### Frontend
- React.js
- Vite
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas
- Mongoose

## API Endpoints

GET /api/leads

POST /api/leads

PUT /api/leads/:id

DELETE /api/leads/:id
